How to Install Your Certificate

Windows Certificate Store

  1. First, download and install the Company CA into Trusted Root Certification Authorities.
  2. Double-click the downloaded .p12 file to open the import wizard.
  3. Select Current User → enter the bundle password you set.
  4. Choose Personal as the certificate store.
  5. Click Finish. Browsers (Chrome, Edge) will pick it up automatically.

macOS Keychain

  1. Download the CA cert and double-click it → add to Login keychain → set trust to Always Trust.
  2. Double-click the .p12 → enter the bundle password.
  3. Open Keychain Access and verify the cert appears under My Certificates.
  4. Safari and Chrome will automatically use it; Firefox may need manual configuration.

Linux / Firefox

  1. Download the CA cert and add it: sudo cp company-ca.crt /usr/local/share/ca-certificates/ && sudo update-ca-certificates
  2. Import the .p12 into Firefox: Settings → Privacy & Security → Certificates → Your Certificates → Import
  3. For Chrome on Linux: pk12util -d sql:$HOME/.pki/nssdb -i your-cert.p12

iOS / iPadOS

  1. Email yourself both the CA cert and the .p12 file, or use AirDrop.
  2. Tap the CA cert → install profile → Settings → General → VPN & Device Management → Install → trust it in Certificate Trust Settings.
  3. Tap the .p12 → install → enter your bundle password.
  4. The certificate will be available system-wide for Safari and managed apps.
